# lakecam/tap

Homebrew casks by Lake Cam.

## Coladrio

A native Mac library for the photos, videos and files you already have: browse by
folder, by date or on a map, with every file opening right inside the app.

```bash
brew install --cask lakecam/tap/coladrio
```

Update with `brew upgrade --cask coladrio`. Requires an Apple silicon Mac with
macOS 14 or later.
